## 状态一致性

`mj_step` 之后 `qpos` / `qvel` 已是新状态，`qfrc_bias` 和稀疏质量 `data.M`（MuJoCo 3.17 里原先的 `qM`）仍是上一步的，直到 `mj_forward`。`compute` 读力矩之前先 `refresh_state`（即 `mj_forward`），所以即使用方漏了同步，τ 用的也是当前 `q`、`q̇`。`M` 用 `mj_fullM`。施加力矩记的是 `qfrc_actuator`，必须在 `mj_step` 之后、下一次 `mj_forward` 之前读，否则会被新状态覆盖。测试用独立的 `mj_forward` 对照每个物理步的 `qfrc_bias` 和 `M`。

力矩只写 6 个臂关节，夹爪保持 position 执行器、开口 0.037。所有控制器的输出按 `actuatorfrcrange` 限幅，每个物理步记录各关节是否饱和。

## 插值与滞后

每个 20 Hz 笛卡尔目标用 DLS IK 解一次，初值是上一个关节解（home 位姿直接用 `home_q`，不积累 IK 漂移）。相邻两个关节目标之间是 Hermite 五次多项式，`s = t / T`，`T = 0.05 s`：

- 端点速度取 `(q_target − q0) / T`，下一段从这个速度开始。`q` 和 `q̇` 在结点连续（C¹），`q̈` 是三次多项式、段内有界，允许在结点跳变。
- 目标在该控制周期**结束**时才到达，所以关节参考比产生它的笛卡尔指令晚一个 20 Hz 节拍，即 50 ms。这一拍里关节参考还在从上一个 IK 解走向当前解，原始笛卡尔路径已经在走向下一个路点。TCP 相对原始参考的误差包含这 50 ms，相对 `FK(q_d)` 的误差才是关节环本身。

速度限制（`configs/m1_pick_place.yaml` 的 `velocity_limit`：腰/肩/肘 2 rad/s，前臂滚转/腕摆/腕转 3 rad/s）：

- 在线：`T` 固定。无约束五次式超速时，把该关节的步长缩小到峰值速度落在 `v_max` 以内（峰值用 201 点估计，内限 `v_max·(1−10⁻³)`）；缩不到就按进入速度滑行。两种回退都把该关节标成速度超限，持续整段。
- 离线：沿同一条笛卡尔路点加密 20 Hz 采样、拉长总时长，直到这条流不再超限。`stretch_joint_trajectory` 用**未限幅**的峰值比来决定拉长倍数，避免限幅后的比值停在 1 附近、时长不再增长。

实验轨迹：home → Can 正上方（+0.08 m）→ 抓取高度（reset 后测到的罐心）→ 抬起 0.10 m → 放置格正上方 → 放置高度 → 再抬起 → home。姿态从上往下，夹爪不动作。段内用五次时间律（路点处笛卡尔速度为 0）再按 20 Hz 采样。运动结束后补一个 50 ms 的追赶拍，再静止 `hold_s = 0.5 s`，稳态误差取这段 `phase == HOLD`。

## 增益

C1–C4 共用一套增益，差别只来自前馈和积分。在 home、夹爪张开时取 `mj_fullM` 对角线（含 armature）：

`M_ii = [0.1194, 0.6486, 0.5307, 0.1525, 0.02104, 0.002600]`

`ω = 20 rad/s`，`ζ = 1`，`Kp = M_ii ω²`，`Kd = 2 ζ M_ii ω`：

`Kp = [47.75, 259.46, 212.27, 61.01, 8.414, 1.040]`

`Kd = [4.775, 25.95, 21.23, 6.101, 0.8414, 0.1040]`

近端和 Menagerie 的 kp 接近（腰 48 对 43，肩 259 对 265，肘 212 对 227）。腕的 `M_ii` 很小，所以腕的 Kp 低于 Menagerie；腕的跟踪主要靠 C3 的 `B q̇_d`。C4 另加 `Ki = Kp · ω / 10`，抗饱和是条件积分：先把积分力矩夹进力矩范围；若未限幅力矩已经越出导轨且误差还在往外推，该关节本步不积分。配置里记了 `Tt = 1/ω`，但没有用反算，因为大的 P 项会把积分往错误方向拉。

## 结论

1. 速度越快，各控制器误差越大，排序稳定：C3 优于 C2，C2 优于 C1，C1 与 C4 接近，位置伺服 B0/B1 最大。fixed_1 的关节 RMSE（fast / medium / slow）为 C3 7.2 / 3.1 / 3.4 mrad，C2 21.9 / 14.9 / 9.6 mrad，C1 24.1 / 19.0 / 15.1 mrad，B1 60.7 / 39.7 / 23.7 mrad。C1 没有前馈，重力和速度项都要从位置误差里挣出来；C2 补上 `g(q)` 之后慢速误差明显下降；C3 再补 `M q̈_d + qfrc_bias + B q̇_d`，fast 误差再降到大约三分之一。C4 的积分跟不上变化的参考，fast 上比 C2 略差（24.1 对 21.9 mrad）。

2. B0 有重力下垂。fixed_1 slow 的 0.5 s 静止段，肩的平均误差 B0 为 +0.022 rad，B1 为 +0.007 rad；肘为 +0.014 rad 对 −0.005 rad。相对参考的稳态 TCP 误差是 10.5 mm 对 2.9 mm。fast 上两者几乎一样（61.5 对 60.7 mrad），惯性滞后盖过了重力偏差。位置执行器全程不饱和，峰值力矩不超过上限的 0.78。

3. 用 Menagerie kp/kv 的 C2 在运动中并不接近 B1。fixed_1 medium 上，C2-menagerie 关节 RMSE 6.5 mrad，B1 是 39.7 mrad。位置律是 `kp·e − kv·q̇ + g`，C2 是 `kp·e + kv·(q̇_d − q̇) + g`。肩在 medium 的峰值 `q̇_d` 约 0.81 rad/s，多出来的 `kv·q̇_d` 可达约 16 Nm，这是位置执行器没有的速度前馈。静止时两项的结构一致；剩下的稳态差（B1 平均绝对误差 6.8 mrad，C2-menagerie 1.4 mrad）和摩擦一致：肩 `frictionloss` 2 Nm 除以 kp 265 约 7.5 mrad，与 B1 的静止误差同量级。

4. 在策略的 20 Hz 和这三档幅度内，关节环跟得住。C3 fast 的关节 RMSE 是 fixed_1 的 7.2 mrad、fixed_2 的 4.5 mrad，最大误差 41 mrad 和 35 mrad。相对 `FK(q_d)` 的 TCP RMSE 是 7.4 mm 和 4.5 mm。相对原始笛卡尔路径更大，19–23 mm RMSE、最大约 56 mm，这是上面的 50 ms 滞后，不是力矩环跟不上 `q_d`。IK 残差保持在 0.1 mm 以内并单独记录。速度超限占比为 0。C3 的饱和只发生在 fast 的肩和肘，原因见上；medium 和 slow 不饱和。slow 的 RMSE 略高于 medium（fixed_1 上 3.41 对 3.11 mrad），因为运动误差已经落到摩擦底（静止平均约 1.9 mrad），主控制器没有积分去消它。增益没有为了抹掉 fast 饱和而降低。

5. 接触实验说明积分项不进主控制器。TCP 被命令到 bin 底板以下 1 cm 并保持约 2 s 再抬起。按压段 C2 不饱和；C4 的肩整段顶在 20 Nm 上，该关节积分被条件积分冻在 0.0079 rad，而没有顶到导轨的 wrist_angle、wrist_rotate 分别积到 0.274 rad 和 0.229 rad。抬起时 C4 的最大关节误差 0.413 rad，C2 是 0.216 rad。两边的 TCP 都没有冲过抬起高度（分别还差 2.2 mm 和 3.9 mm）。抬起后的 0.5 s 里，C4 的平均关节误差仍有 0.106 rad、TCP 49 mm，C2 是 0.0058 rad 和 2.7 mm：没饱和的关节上的积分还没泄掉。条件积分能停住已经饱和的关节，停不住那些始终在力矩范围里的关节。
