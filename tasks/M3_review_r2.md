## 最终结论（提交用户审批）

框架、状态一致性、控制律、日志和批量实验都合格。**需要修改**（发回 Cursor 原对话 `ctx_be35b1b8e7c6`，当前用量 27.7%）：

1. **参考轨迹生成（F1，必修）**
   - 重新设计 20 Hz → 500 Hz 的参考生成，让 q_d、q̇_d、q̈_d 来自**同一条**平滑轨迹，结点处的加速度不能被强制为 0。
   - 至少比较两种方案，例如：(a) 缓存一个未来目标，用中心斜率加完整的五次 / 三次样条，这样会多 50 ms 的滞后；(b) 不看未来目标的因果方案，对加速度或 jerk 设上界。每种方案都要写清总滞后。
   - 选定的方案用于环境类（后续的策略也会用它），并重跑全部 39 组实验。
   - 验收：
     - 给出新旧方案的对比表，包括关节 RMSE、相对原始参考的 TCP 误差（反映滞后的代价）、各关节的饱和占比、命令峰值和 q̈_d 纹波；纹波用频谱或段内残差来衡量。
     - q_d、q̇_d 连续；速度限幅保持不变。
     - 有停止、反向的测试。
2. **速度回退 bug（N1，必修）**：起始速度位于速度上限或接近上限时，必须能在有限时间内制动或换向，同时保持 C¹ 连续和速度限幅。验收：Codex 给出的复现用例 `plan_segment(q=[0], v=[1], q_target=[-1], T=.05, v_max=[1])` 不再一直沿原方向滑行；补充停止 / 反向的序列测试。
3. **Can 位姿与接触（F2）**：日志中加入 Can 位姿和“手指与 Can 是否接触”的标记，汇总表加入 Can 的最大位移和接触步数。如果主实验中有接触，在**不改变参考几何**的前提下把 Can 移开，再重跑。
4. **C2 结构一致对照（F3）**：加一组 `C2_menagerie_noff`（阻尼项写成 `−kv·q̇`），报告它与 B1 的 q 轨迹最大差。如果超过 1e-3 rad，在同一状态下对比两者的力矩，说明差异来源。
